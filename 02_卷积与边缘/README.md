# 第 2 章：卷积与边缘

本章用时建议 **5–7 小时**。目标是理解局部加权、带符号梯度与边缘阈值之间的关系。

## 学习顺序

1. 阅读 `教程_卷积与边缘.md`（原教程保留）。
2. 运行 `实验_卷积与边缘.ipynb`，改变噪声、平滑尺度和 Canny 阈值。
3. 独立完成 `2-1_手写相关运算.py`，不要复制 Notebook 中的 OpenCV 基线。
4. 运行 `python tests/check_progress.py`。
5. 填写 `实验记录.md`，保留一次过度平滑或阈值失效案例。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_卷积与边缘.md` | 原理与方法边界 |
| `实验_卷积与边缘.ipynb` | 合成阶跃图上的 Sobel/Canny 互动实验 |
| `2-1_手写相关运算.py` | 手写二维相关作业 |
| `tests/check_progress.py` | shape、dtype、恒等核与常量响应检查 |
| `data/README.md` | 数据与许可说明 |
| `实验记录.md` | 参数、结果和失败分析模板 |

## 启动与验收

在课程根目录运行 `python -m jupyter lab .`，选择 `cv-learning` 内核。进入本章目录后运行：

```bash
python tests/check_progress.py
```

未完成时显示 `TODO`；错误显示 `FAIL`；满足基本不变量显示 `PASS`。自动测试只是底线。

## 通过标准

- 能解释相关与严格卷积的差异。
- 导数计算保留带符号浮点结果。
- 能说明平滑尺度、定位精度与噪声抑制的取舍。
- 作业通过检查，并记录至少一个 Canny 断边或误检案例。
