# 第 10 章：迁移学习与 Grad-CAM

本章在合成条纹图上预训练一个极小 CNN，再冻结特征层训练新分类头，并生成 Grad-CAM。实验不加载任何在线权重。

## 学习顺序

1. 阅读 `教程_迁移学习与模型分析.md`。
2. 运行 `实验_迁移学习与GradCAM.ipynb`，比较冻结与微调。
3. 完成 `作业_冻结策略与热图归一化.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 记录可训练参数、热图和捷径学习失败案例。

## 文件说明

| 文件 | 作用 |
|---|---|
| `实验_迁移学习与GradCAM.ipynb` | 合成预训练、线性探测与 Grad-CAM |
| `作业_冻结策略与热图归一化.py` | 参数冻结策略与热图后处理契约 |
| `tests/check_progress.py` | 检查可训练参数集合、shape 与数值范围 |
| `data/README.md` | ImageNet、Flowers102 等官方来源与许可提示 |

Notebook 使用自己训练的微型模型，避免联网和大权重依赖；热图仅用于相关性检查，不当作因果证明。
