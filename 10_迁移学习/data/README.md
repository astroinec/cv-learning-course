# 第 10 章数据说明

默认实验完全使用合成条纹图，并从随机初始化开始预训练极小网络；不会访问在线权重。

## 可选官方来源与权重

- Oxford 102 Flowers 官方页面：<https://www.robots.ox.ac.uk/~vgg/data/flowers/102/>
- torchvision Flowers102 文档：<https://pytorch.org/vision/stable/generated/torchvision.datasets.Flowers102.html>
- PyTorch torchvision 模型与权重文档：<https://pytorch.org/vision/stable/models.html>

花卉图片和标注可能有各自的研究用途、引用或再分发限制；预训练权重也可能带有独立许可。下载前应同时核对数据集页面、权重枚举文档和模型仓库许可。本课程不自动下载，也不把大权重提交到章节目录。

记录数据来源、权重标识、预处理版本、许可和哈希，才能复现实验。
