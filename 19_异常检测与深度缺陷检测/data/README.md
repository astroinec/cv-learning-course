# 第 19 章数据说明

迷你实验只用代码生成的条纹纹理。

公开数据：

- [MVTec AD](https://www.mvtec.com/company/research/datasets/mvtec-ad)：15 类，像素级标注，许可 CC BY-NC-SA 4.0，仅限非商业用途。建议先下 bottle 或 grid 一个类别。
- [VisA](https://github.com/amazon-science/spot-diff)：12 类，含 PCB，许可 CC BY 4.0。

下载后放 `data/external/`，不要提交到仓库。Anomalib 也可以自动下载 MVTec AD。
