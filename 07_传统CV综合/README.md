# 第 7 章：相机与三维视觉

本章用时建议 **6–8 小时**。目标是打通世界坐标、相机坐标、归一化坐标与像素坐标的投影链路。

## 学习顺序

1. 阅读 `教程_相机与三维视觉.md`（原教程保留）。
2. 运行 `实验_相机与三维.ipynb`，改变立方体深度和旋转角。
3. 独立完成 `7-1_针孔投影.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 中记录近零深度、点在相机后方或内参错误的表现。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_相机与三维视觉.md` | 相机模型、PnP 与对极几何教程 |
| `实验_相机与三维.ipynb` | 合成立方体的相机投影互动实验 |
| `7-1_针孔投影.py` | 从零实现无畸变针孔投影 |
| `tests/check_progress.py` | 主点、深度尺度与无效深度检查 |
| `data/README.md` | 数据与标定建议 |
| `实验记录.md` | 实验记录模板 |

## 启动与验收

从课程根目录运行 `python -m jupyter lab .` 并选择 `cv-learning`。本章目录执行：

```bash
python tests/check_progress.py
```

## 通过标准

- 能写出 `s p = K[R|t]P` 并说明各 shape。
- 能解释为什么同一视线上的不同深度投到同一像素。
- 知道 `rvec` 不是三个欧拉角，`tvec` 也不是相机世界坐标。
- 作业通过检查并记录至少一个三维投影失效案例。
