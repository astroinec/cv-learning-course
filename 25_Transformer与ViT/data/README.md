# 第 25 章数据说明

作业、验收、Notebook 和教程配图用的全部是代码生成的小图：噪声背景上放 3×3 的横线、竖线、斜线、反斜线图案，或者 2×2 的亮斑。不需要下载任何数据，这个目录平时是空的。

教程第 10 节（在自己的机器上用真模型）需要：

- torchvision 的 `vit_b_16` 预训练权重。第一次加载时由 torchvision 自动下载到它自己的缓存目录，不放在这里。权重的来源、许可和大小以 torchvision 文档里对应的模型卡为准。
- 几张自己的图像。建议用和工作相关的检测图；没有的话可以用第 19 章 `data/README.md` 里列的公开数据集（注意那里写的许可限制）。

自己准备的图像放 `data/external/`，不要提交到仓库。
