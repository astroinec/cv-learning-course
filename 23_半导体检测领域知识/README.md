# 第 23 章：半导体检测领域知识

本章用时建议 **6–10 小时**，以阅读为主，配一个晶圆几何的小作业。目标：入职第一周能听懂会议上的术语，知道检测在整个制造流程里的位置，知道自己做的算法最终影响哪些指标。

## 为什么重要

工业视觉和学术视觉最大的区别在领域知识。同样一个“检测”，在半导体里有严格的术语、流程和指标，不懂这些很难判断一个算法改进到底有没有业务价值。这一章不追求深，追求“不外行”。

## 学习顺序

1. 阅读 `教程_半导体检测领域知识.md`，把术语表抄进自己的笔记。
2. 实现 `23-1_晶圆图.py`，运行验收。
3. 运行 `实验_晶圆图.ipynb`：画出 300 mm 晶圆的 die 网格，合成几种典型的缺陷空间分布（随机、中心、边缘环、划痕），用径向密度和边缘比例区分它们。
4. （选做）下载 WM-811K 晶圆图数据集，看真实的空间模式长什么样。
5. 在 `实验记录.md` 整理一页“入职前术语清单”，标出自己还不确定的词，入职后第一周去问。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_半导体检测领域知识.md` | 制造流程、晶圆与 die、缺陷类型、检测设备分类、指标和术语 |
| `实验_晶圆图.ipynb` | 晶圆图可视化与空间模式 |
| `23-1_晶圆图.py` | 作业：die 网格、缺陷归属、径向密度、边缘比例 |
| `tests/check_progress.py` | 自动验收 |
| `实验记录.md` | 术语清单与实验记录模板 |

## 通过标准

- 4 项测试 PASS。
- 能用自己的话说清楚：缺陷检测（inspection）、缺陷复查（review）、量测（metrology）的区别。
- 能说出至少 6 种常见缺陷类型，以及它们大致来自哪道工序。
- 能解释检出率、误报率、产能、良率之间的关系。

## 推荐资源

- 维基百科条目：[Semiconductor device fabrication](https://en.wikipedia.org/wiki/Semiconductor_device_fabrication)、[Wafer (electronics)](https://en.wikipedia.org/wiki/Wafer_(electronics))、[Die (integrated circuit)](https://en.wikipedia.org/wiki/Die_(integrated_circuit))，快速建立整体图景。
- 检测设备厂商的公开技术介绍（KLA、Applied Materials、Hitachi High-Tech 以及国内厂商的官网产品页和白皮书）：看他们怎么描述明场、暗场、电子束检测，以及灵敏度和产能指标。
- WM-811K 晶圆图数据集：约 81 万张晶圆图，标注了 9 种空间模式，搜索“WM-811K wafer map”可以在 Kaggle 找到。
- 入职后最好的资料是公司内部的设备手册和配方文档，本章只是帮你看懂它们。
