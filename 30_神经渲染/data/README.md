# 第 30 章数据说明

作业、验收、Notebook 的必做部分和教程里的全部数字，都只用代码生成的一个小场景：两个球、一个盒子、一块棋盘格底板，表面是漫反射。训练图是 32×32 的，由已知的针孔相机（OpenCV 约定）用光线和几何体求交直接算出来，同时得到每个像素的深度真值。不需要下载任何数据。

教程第 9 节（深挖档）要用自己拍的照片或者公开数据：

- 自己拍：选一个不反光、有纹理、放着不动的小物体，围着它拍几十张到一百来张，相邻两张之间重叠要多。镜面、透明的东西和大片没有纹理的表面最容易失败，第一次不要选。
- 公开数据：NeRF 论文的合成场景（常被称为 Blender 或 NeRF Synthetic，带现成的相机位姿）和 Mip-NeRF 360 的真实场景是这个方向最常用的两组。下载地址和许可以各自的项目页和 nerfstudio 的文档为准。

照片、COLMAP 的输出和训练出来的模型放 `data/external/`，不要提交到仓库。训练出来的高斯点云文件可能很大，大小以实际为准。
