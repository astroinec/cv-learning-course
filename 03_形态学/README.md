# 第 3 章：形态学

本章用时建议 **4–6 小时**。目标是把二值前景视为集合，理解结构元素如何编码形状与尺度先验。

## 学习顺序

1. 阅读 `教程_形态学.md`（原教程保留）。
2. 运行 `实验_形态学.ipynb`，改变结构元素尺寸与操作类型。
3. 独立完成 `3-1_手写二值形态学.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 中记录一次目标被误删或错误粘连的案例。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_形态学.md` | 二值化、形态学与连通域教程 |
| `实验_形态学.ipynb` | 合成二值图上的开闭运算互动实验 |
| `3-1_手写二值形态学.py` | 手写腐蚀与膨胀作业 |
| `tests/check_progress.py` | 二值性、包含关系与边界案例检查 |
| `data/README.md` | 数据说明 |
| `实验记录.md` | 实验记录模板 |

## 启动与验收

从课程根目录运行 `python -m jupyter lab .` 并选择 `cv-learning`。本章目录执行：

```bash
python tests/check_progress.py
```

检查器把未实现标为 `TODO`，不会因占位函数崩溃。

## 通过标准

- 明确非零像素是前景。
- 能从顺序推导开运算与闭运算作用。
- 能解释结构元素方向和尺度的含义。
- 作业通过检查并记录至少一个结构元素失配案例。
