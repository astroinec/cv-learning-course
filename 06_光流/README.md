# 第 6 章：光流

本章用时建议 **5–7 小时**。目标是理解亮度恒定、小运动、邻域同运动假设及前向—反向一致性。

## 学习顺序

1. 阅读 `教程_光流与运动.md`。
2. 运行 `实验_光流.ipynb`，改变合成位移与窗口大小。
3. 独立完成 `6-1_前向反向筛选.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 中记录大位移、边界或亮度变化的失败案例。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_光流与运动.md` | LK、金字塔和稠密光流教程 |
| `实验_光流.ipynb` | 已知平移的合成纹理流场实验 |
| `6-1_前向反向筛选.py` | 根据状态与往返误差过滤轨迹 |
| `tests/check_progress.py` | bool mask、状态过滤与阈值边界检查 |
| `data/README.md` | 数据说明 |
| `实验记录.md` | 实验记录模板 |

## 启动与验收

从课程根目录运行 `python -m jupyter lab .` 并选择 `cv-learning`。本章目录执行：

```bash
python tests/check_progress.py
```

## 通过标准

- 能写出光流约束方程并解释孔径问题。
- 知道光流单位通常是像素/帧。
- 会结合 `status` 和前向—反向误差拒绝坏点。
- 作业通过检查并记录至少一个假设失效案例。
