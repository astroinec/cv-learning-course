扩散模型的前向过程：步数、噪声表和分辨率（第 20 章）

前向加噪 x_t = sqrt(ᾱ_t)·x_0 + sqrt(1 - ᾱ_t)·ε，和作业里的 q_sample 是同一个公式，t 从 0 数起。拖动步数时用的是同一份噪声 ε。所有计算在浏览器里完成，不执行 Python。
ᾱ_t（累计保留的信号比例）
信噪比 ᾱ_t / (1 - ᾱ_t)
x_t 和 x_0 逐像素的相关系数
块平均到 32×32 之后的相关系数
按顺序试
  1. 线性表、1000 步、32×32。把 t 从 0 慢慢拖到 300，看条纹什么时候认不出来。t=300 时 ᾱ 还有 0.39，逐像素的相关系数已经掉到 0.30 左右。
  2. t=500。线性表的信噪比只有 0.08，图上几乎只剩噪声；切到余弦表，同样是第 500 步，信噪比约为 1，逐像素的相关系数从 0.11 回到 0.35，亮斑又隐约看得出来。
  3. 线性表，t=674，信噪比刚好掉到 0.01 以下。往右一直到 999，将近三分之一的步数都在这条线下面。切到余弦表，要到第 936 步才掉到 0.01 以下。
  4. 回到线性表、t=300，把分辨率从 32 换到 64、128。同一个步数，画面里的条纹越来越清楚，块平均到 32×32 之后的相关系数从 0.30 升到 0.53、0.78。
  5. 把总步数改成 100、β 的范围不变，t 拖到最后一步 99：ᾱ 还有 0.36，x_t 远不是纯噪声。再点“100 步，β 放大”（β 整体乘 10），最后一步的 ᾱ 回到 0.00002。
线性表：β 从 0.0001 到 0.02 等间隔（“β 放大”时是 0.001 到 0.2）。余弦表：ᾱ_t = f(t+1)/f(0)，f(i) = cos²(((i/T + 0.008)/1.008)·π/2)，β 截到 0.999。场景先在 256×256 上画好，再块平均到所选的分辨率，所以三种分辨率是同一张图。KPI 里的大字是按公式算的，小字是这一份噪声上实测的。
