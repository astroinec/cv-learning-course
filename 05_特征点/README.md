# 第 5 章：特征点

本章用时建议 **5–7 小时**。目标是理解角点可追踪性的来源，以及检测、描述、匹配和几何验证的分工。

## 学习顺序

1. 阅读 `教程_特征点与描述子.md`。
2. 运行 `实验_特征点.ipynb`，改变旋转角和质量阈值。
3. 独立完成 `5-1_Harris响应.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 中记录平坦区、边缘和角点响应差异。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_特征点与描述子.md` | Harris、SIFT、ORB 和匹配教程 |
| `实验_特征点.ipynb` | 合成棋盘上的角点重复性实验 |
| `5-1_Harris响应.py` | 手写 Harris 响应作业 |
| `tests/check_progress.py` | shape、有限值、平坦区与角点不变量检查 |
| `data/README.md` | 数据说明 |
| `实验记录.md` | 实验记录模板 |

## 启动与验收

从课程根目录运行 `python -m jupyter lab .` 并选择 `cv-learning`。本章目录执行：

```bash
python tests/check_progress.py
```

## 通过标准

- 能用结构张量特征值区分平坦、边缘和角点。
- 知道 Harris 响应图还需阈值与非极大值抑制。
- 能为浮点和二进制描述子选择正确距离。
- 作业通过检查并记录一次阈值或旋转导致的失效。
