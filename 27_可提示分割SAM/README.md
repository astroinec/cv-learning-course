# 第 27 章：可提示分割 SAM

本章用时：速通 **2 小时**，标准 **8 小时**，深挖 **14 小时**（深挖档含在自己的显卡上跑官方 SAM），各档做什么见教程第 0 节。目标：理解“图像编码一次、提示解码多次”的可提示分割结构，亲手实现提示编码和掩码后处理的五个零件，用一个能在 CPU 上训练的小模型把歧义、预测 IoU、交互修正和全图自动分割量出来，知道它在缺陷标注里帮得上和帮不上的地方。

## 为什么重要

缺陷分割模型要像素级的掩码当标签，一张图一张图地描边很慢。可提示分割把“描边”换成“点一下或框一下，模型出掩码，人再修”，是半自动标注工具背后的做法。它也能接在别的模块后面：检测框、异常热图的峰值都可以当提示。但它不是万能的，低对比度、极小、只靠纹理区分的目标正好是工业检测里常见的，本章用小模型把这些限制测出来。

## 学习顺序

1. 复习第 12 章（Dice、IoU、小目标的指标问题）和第 25 章（注意力、位置编码）。
2. 阅读 `教程_可提示分割.md`，把第 9 节的交互演示五步试一遍。
3. 实现 `27-1_提示与掩码后处理.py`，运行验收。
4. 运行 `实验_可提示分割.ipynb`：写完 `point_position_encoding` 和 `mask_to_box` 就能训练 `迷你SAM.py` 里的小模型，其余函数在后面的实验里用到。
5. 做教程第 14 节前三个破坏实验，在 `实验记录.md` 里填表。
6. 深挖档：按教程第 11 节在自己的机器上装官方 `segment-anything`，在自己的图像上重做点提示、框提示和全图自动分割。

## 通过标准

- 5 项测试 PASS。
- 能画出“图像编码器、提示编码、掩码解码器”三块的关系，说清哪一块每张图只跑一次。
- 能解释为什么一个点会有几个合理答案，只输出一个掩码时会发生什么，多输出训练时为什么只回传最好的那个。
- 能说出预测 IoU 和稳定性分数各在衡量什么，全图自动分割的三步各去掉什么。
- 能举出可提示分割在缺陷标注里帮不上的三种情况，并说明换成真模型时哪些结论要自己重测。

## 推荐资源

- 论文：Kirillov 等，Segment Anything（ICCV 2023），即 SAM。重点读模型结构、歧义处理和数据引擎三部分。
- 论文：Ravi 等，SAM 2: Segment Anything in Images and Videos（2024），把可提示分割扩展到视频。
- 官方仓库 `segment-anything`（GitHub 上 facebookresearch 组织下）：`SamPredictor`、`SamAutomaticMaskGenerator` 的源码不长，读一遍能和本章的小模型逐块对上。权重下载链接和许可以仓库 README 为准。
- 官方仓库 `sam2`（同一组织）：SAM 2 的代码和权重，接口以它的 README 为准。
- 本章不依赖任何公开数据集。想在工业图像上试，可以用第 19 章 `data/README.md` 里列的 MVTec AD 或 VisA（注意各自的许可）。
