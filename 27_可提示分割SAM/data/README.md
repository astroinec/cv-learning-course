# 第 27 章数据说明

作业、验收、Notebook 和教程里的全部实验只用代码生成的合成图：64×64 的灰度图，上面有两三个可能互相遮挡的形状，形状里可能套着部件和小部件，带平滑纹理和白噪声。生成器是 `迷你SAM.py` 里的 `make_scene`，固定随机种子，不需要下载任何东西。

深挖档在自己的图像上试官方 SAM 时：

- 权重从官方仓库 `segment-anything` 的 README 给的链接下载，三种规模选哪个见教程第 11 节。权重文件放 `data/external/`，不要提交到仓库。
- 想用公开的工业图像，可以用第 19 章 `data/README.md` 里列的 MVTec AD 或 VisA，许可以各自的页面为准。
- 自己的产线图像不要放进仓库。
