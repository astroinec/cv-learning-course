# 第 8 章：神经网络基础

本章用一个无需下载数据的 XOR 小实验建立“前向传播—损失—反向传播—更新”的最小闭环。

## 学习顺序

1. 阅读 `教程_神经网络基础.md`。
2. 顺序运行 `实验_XOR与反向传播.ipynb`，修改隐藏维度、学习率和随机种子。
3. 完成 `作业_手写两层网络.py` 中的 TODO。
4. 运行 `python tests/check_progress.py`。
5. 将曲线、梯度检查和失败案例写入 `实验记录.md`。

## 文件与契约

| 文件 | 作用 |
|---|---|
| `实验_XOR与反向传播.ipynb` | 合成 XOR 数据、训练两层网络并观察决策边界 |
| `作业_手写两层网络.py` | NumPy 两层网络的前向与交叉熵作业 |
| `tests/check_progress.py` | 检查 shape、数值范围与未完成状态 |
| `data/README.md` | 可选官方数据来源与许可提示 |

Notebook 只演示 PyTorch 自动微分，不给出 NumPy 作业完整实现。所有样例都在内存中合成，不联网。

## 通过标准

- 能解释 `(B, D) -> (B, H) -> (B, C)` 的 shape 变化。
- 能说明 logits 与概率的区别，以及交叉熵为何直接接 logits。
- 能观察到激活函数、学习率或标签噪声导致的失败模式。
- 作业检查器最终显示 `PASS`；初始 `TODO` 是正常状态。
