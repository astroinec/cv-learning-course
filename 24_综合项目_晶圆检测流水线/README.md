# 第 24 章：综合项目，合成晶圆 die-to-die 检测流水线

本章用时建议 **12–20 小时**。目标：把对齐、亮度归一化、金模板、阈值、连通域和指标评估串成一条完整流水线，在带真值的合成数据上达到检出率不低于 85%、每 die 误报不超过 0.3，并写一份像样的项目报告。

## 场景

一批 die 被相机拍下来，每张图都有：

- 机台定位误差导致的随机亚像素错位（最大约 ±3.5 px）
- 光学模糊、照明亮度和偏置漂移（增益 ±15%，偏置 ±0.05）
- 散粒噪声和读出噪声
- 部分 die 上有 1 到 3 个缺陷：颗粒（亮或暗）、短划痕、图形缺失

另外有 8 张已知良品 die。你要找出每张待检 die 上的缺陷位置。

版图是周期结构，左上角有一个对位十字标记。数据生成器 `数据生成.py` 已经写好，**建议读一遍它的源码**，这是一个典型的“程序化合成加成像仿真”的例子（第 20、22 章）。

## 学习顺序

1. 运行 `python3 24_综合项目_晶圆检测流水线/数据生成.py`，看数据规模。
2. 运行 `实验_流水线调试.ipynb`：可视化原图、对齐后的图、差分图、z 图、检测结果和真值，逐步调试。
3. 在 `24-1_检测流水线.py` 实现 `run_pipeline`，可以用 `load_chapter` 导入前面章节自己写的函数。
4. 运行 `python3 24_综合项目_晶圆检测流水线/tests/check_progress.py`。
5. 通过后做消融实验，按 `项目报告模板.md` 写报告，保存为 `项目报告.md`。
6. （进阶）把流水线里最耗时的一步用 C++ 重写（第 15 章），对拍结果一致，比较耗时。

## 验收要求

- 两个种子都满足：检出率 ≥ 85%，每 die 误报 ≤ 0.3，单次运行 ≤ 30 秒。
- 流水线只能读 `golden` 和 `test`，不能读真值和真实错位。
- 指标由验收脚本根据真值独立计算，不能用流水线自己报告的数字。

## 已知的坑

这些是课程开发时真实踩过的，留给你自己去复现和解决：

1. **周期图案的假峰**：版图在 x 方向是周期结构，相位相关不加约束时可能对到整周期之外，误差接近 24 px。想想第 16 章教程第 7 节的应对办法。
2. **加窗不一定更好**：这份数据是循环平移生成的，加 Hanning 窗反而让对齐残差从约 0.15 px 增大到约 0.35 px。用数据说话。
3. **照明漂移**：不做亮度归一化，误报会明显上升，检出率会下降。
4. **坐标系**：验收用的是每张 die 自身的图像坐标，你在对齐坐标系里找到的缺陷要变换回去。

## 参考水平

参考实现（在仓库的 `solutions` 分支，建议验收通过后再看）在验收种子上检出率约 91% 到 93%、误报接近 0；在另外 10 个种子上检出率 88% 到 97%。消融结果：不对齐时检出率为 0，不做亮度归一化时检出率约 61% 到 64%、每 die 误报约 0.5 到 0.9。你的结果和这些数字差得多时，先逐步看中间结果。

## 通过标准

- 验收通过。
- 报告里有消融表（至少去掉对齐、去掉归一化、改变 k 三组），有漏检样本的逐个分析，有阈值和检出率、误报率的关系曲线。
- 能在 5 分钟内把这条流水线讲给一个面试官听，说清每一步为什么需要。
