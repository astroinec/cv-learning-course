# 第 26 章：自监督基础模型：MAE 与 DINOv2

本章用时：速通 **3 小时**，标准 **10 小时**，深挖 **16 小时**（深挖档含在自己的显卡上跑 DINOv2 的预训练权重），各档做什么见教程第 0 节。目标：弄清掩码图像建模和自蒸馏这两种不用标签的预训练各靠什么学到特征、各在什么条件下失效，亲手实现它们的五个核心零件，会用线性探测、k 近邻和检索评价一个冻结的特征，并且知道把预训练好的 DINOv2 当特征提取器接到异常检测上时该怎么做、限制在哪。

## 为什么重要

检测场景里缺陷样本少、标注贵，新产品上线时连一个像样的训练集都凑不出来。这时最常见的起点不是训练一个网络，而是拿一个在大量无标签图像上预训练好的通用特征，冻结它，后面只接 k 近邻或者一个线性头。第 19 章的 PatchCore 就是这个思路，把它的 ResNet 骨干换成自监督训练的 ViT，是这几年工业异常检测里很常见的做法。会用不难，难的是知道特征什么时候靠得住：它是怎么训练出来的、哪些信息被保留、哪些被丢掉、分辨率够不够看见你的缺陷。

## 学习顺序

1. 复习第 25 章（Transformer 与 ViT）、第 13 章 5.1 和 5.2 节（对比学习、MAE 的思路）、第 10 章 10.1 节和“特征缓存”一小节（线性探测）。
2. 阅读 `教程_自监督基础模型.md`。
3. 实现 `26-1_掩码建模与自蒸馏.py`，运行验收。
4. 运行 `实验_自监督基础模型.ipynb`：用你写的零件在 CPU 上训练一个迷你 MAE 和一个迷你自蒸馏模型，看重建、看坍缩、用 k 近邻评价特征，再用冻结的块特征做一次异常检测。
5. 做教程第 10 节的破坏实验，前三个必做。
6. 深挖档：按教程第 6 节在自己的机器上加载 DINOv2 的预训练权重，取类别标记和块特征，做 k 近邻和主成分可视化。
7. 在 `实验记录.md` 写下：两种坍缩各自的熵是多少，冻结特征在你的数据上 k 近邻和线性探测各是多少、用了多少标签。

## 通过标准

- 5 项测试 PASS。
- 能画出 MAE 的数据流：切块 → 随机遮挡 → 编码器只处理可见块 → 补上掩码标记和位置编码 → 轻量解码器 → 只在被遮块上算损失。
- 能说清自蒸馏里教师、学生、滑动平均、中心化、锐化各起什么作用，去掉中心化和去掉锐化分别坍缩成什么样，用哪两个量能把它们分开。
- 能解释为什么评价通用特征要同时看线性探测和 k 近邻，以及有监督预训练的特征换一个任务时为什么可能不如自监督的。
- 能说出把冻结的 ViT 块特征用于缺陷检测时的三个限制：域差异、块的分辨率、小缺陷。

## 本章额外需要的包

作业、验收、Notebook 的必做部分只用 numpy、torch、matplotlib，不需要额外安装。教程第 6 节和 Notebook 的选做单元要用预训练权重，有两条路，任选其一：

- `torch.hub`：不需要额外的包，但第一次运行要联网下载官方仓库的代码和权重。
- Hugging Face `transformers`：`pip install transformers`，第一次运行同样要联网下载权重。

环境安装见 `docs/环境安装.md`。

## 推荐资源

- 论文：He 等，Masked Autoencoders Are Scalable Vision Learners（CVPR 2022），即 MAE。官方仓库 `facebookresearch/mae`。
- 论文：Caron 等，Emerging Properties in Self-Supervised Vision Transformers（ICCV 2021），即 DINO。官方仓库 `facebookresearch/dino`。
- 论文：Oquab 等，DINOv2: Learning Robust Visual Features without Supervision（2023）。官方仓库 `facebookresearch/dinov2`，仓库的说明里有各个模型的名称和用法。
- 论文：Zhou 等，iBOT: Image BERT Pre-Training with Online Tokenizer（ICLR 2022）。DINOv2 的块级损失来自这里。
- 论文：Darcet 等，Vision Transformers Need Registers（ICLR 2024）。解释 DINOv2 块特征图上的异常亮点，以及带寄存器标记的版本。
- Hugging Face `transformers` 文档里的 DINOv2 页面：`AutoModel`、`AutoImageProcessor` 的用法和各个权重的模型卡。
- 第 19 章推荐的 Anomalib 和 MVTec AD：把预训练特征换成 DINOv2 之后在公开数据上对比时用。
