# 第 22 章：成像与设备仿真

本章用时建议 **10–14 小时**。目标：建立从“物体”到“像素值”的完整成像模型，包括光学分辨率、照明方式、PSF、采样和传感器噪声；能写一个可验证的成像仿真器，用它回答“这台设备能不能看见这种缺陷”。

## 为什么重要

JD 里两次提到“检测设备的建模仿真”和“数据生成”。算法工程师需要懂成像，原因有三：知道算法的上限在哪里（光学分辨率以下的缺陷算法救不回来），能用仿真数据测试算法，能和光学、硬件工程师用同一套语言讨论问题。

## 学习顺序

1. 阅读 `教程_成像与设备仿真.md`。
2. 看 First Principles of Computer Vision 的 Image Sensing 模块和 Depth from Defocus 模块里的 Point Spread Function 一节。
3. 实现 `22-1_成像仿真.py`，运行验收。
4. 运行 `实验_成像仿真.ipynb`：同一个小缺陷，在不同 NA、像素尺寸、曝光量下仿真，画出“缺陷信噪比 vs 缺陷尺寸”曲线。
5. 在 `实验记录.md` 写下：在你设定的参数下，最小可检出缺陷有多大，依据是什么。

## 通过标准

- 4 项测试 PASS，能从仿真数据恢复增益和读出噪声。
- 能估算：给定波长和 NA，光学分辨率多少；给定分辨率，像素尺寸该选多大。
- 能解释明场和暗场照明分别对什么缺陷敏感。
- 能写出散粒噪声和读出噪声的方差公式，说清楚曝光量翻倍时信噪比怎么变。

## 推荐资源

- First Principles of Computer Vision：Image Formation（透镜成像、景深）、Image Sensing（传感器、分辨率、噪声、动态范围）、Depth from Defocus（点扩散函数），[课程网站](https://fpcv.cs.columbia.edu/)。
- [MIT 6.801 Machine Vision](https://ocw.mit.edu/courses/6-801-machine-vision-fall-2020/)：前几讲的成像几何和辐射度学。
- EMVA 1288 标准：工业相机性能测量的标准，光子转移曲线（PTC）方法的来源，相机规格书上的量子效率、满阱、暗噪声都按它定义。
- Joseph Goodman，Introduction to Fourier Optics：傅里叶光学的经典教材，想深入理解 PSF 和 MTF 时再读。
