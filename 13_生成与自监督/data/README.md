# 第 13 章数据说明

默认实验使用随机生成的条纹与噪声，不依赖图片文件。

## 可选官方来源

- MNIST 官方页面：<http://yann.lecun.com/exdb/mnist/>
- CIFAR-10/100 官方页面：<https://www.cs.toronto.edu/~kriz/cifar.html>
- LAION 官方项目页：<https://laion.ai/>

生成与自监督任务常使用大规模无标签或图文数据，但“公开可访问”不等于“可任意再分发”。使用前应核对数据集、元数据和原始图片各自的许可、隐私、肖像权、版权及删除机制。LAION 类数据通常提供索引或元数据，原始内容的权利状态需逐项判断。

本课程不下载数据。若自行构建小数据集，应保存来源清单与许可字段，并排除敏感、个人身份或不适合训练的内容。
