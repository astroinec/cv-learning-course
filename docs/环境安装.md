# 环境安装（Windows 为主）

> 课程是给一台中文 Windows 笔记本（NVIDIA RTX 4060，8 GB 显存）写的，但写课程和做全部实测的机器是一台 Apple 芯片的 Mac。下面的 Windows 步骤按各工具的官方做法整理，**没有在 Windows 上实际走过一遍**。第一次照做时请按第 7 节逐项确认，遇到和这里不一致的情况，以你机器上的报错和工具的官方页面为准。

## 1. 需要准备什么

| 组件 | 必需吗 | 用在哪 |
|---|---|---|
| Git | 必需 | 克隆仓库、切换到 `solutions` 分支对照参考答案 |
| Python 3.12（64 位） | 必需 | 全部作业、验收、Notebook。3.10 到 3.13 都应该可以，课程在 3.12 上测过 |
| 课程的 Python 包 | 必需 | 第 3 节，`requirements.txt` |
| 带 CUDA 的 PyTorch | 推荐 | 第 8 到 14 章、第 19 到 20 章、第三部分用显卡会快很多。不装也能学：课程里所有实验都按“CPU 上几分钟跑完”设计 |
| NVIDIA 显卡驱动 | 用显卡时必需 | 带 CUDA 的 PyTorch 只要求驱动，**不需要另装 CUDA Toolkit 和 cuDNN** |
| C++ 编译器 | 第 15 章必需 | 第 6 节。只有第 15 章用到 |
| Chrome 或 Edge | 推荐 | 看课程网页和交互演示 |
| 第三部分的可选包 | 可选 | 第 25 到 31 章的“在自己的机器上用真模型”一节，第 5 节 |

磁盘：仓库本身约 50 MB，虚拟环境（带 CUDA 的 PyTorch）约 5 到 6 GB，第三部分如果下载预训练模型，另需几 GB 到十几 GB。

## 2. 安装 Git 和 Python

1. **Git**：到 Git 官网下载 Git for Windows 安装，一路默认即可。也可以在 PowerShell 里运行 `winget install --id Git.Git -e`。
2. **Python 3.12**：到 python.org 下载 Windows 64 位安装包。安装时勾选 “Add python.exe to PATH”。装好后新开一个 PowerShell，运行 `py -3.12 --version` 或 `python --version`，能看到 3.12.x 就可以。
   - 不要用应用商店里的 Python，也不建议用 MSYS2 自带的 Python 运行课程（第 15 章验收按 Windows 版 Python 写的）。
   - 用户名是中文时，Python 本身没有问题，但个别工具在含中文的路径下会出错。仓库建议放在纯英文路径下，例如 `D:\study\cv-learning-course`。仓库里的章节目录名是中文，课程的脚本已经按这一点处理过。

## 3. 克隆仓库，建虚拟环境，装依赖

**最省事的办法**：克隆后双击仓库根目录的 `安装环境.bat`，它会依次做下面第 3.2 到 3.4 步，最后打印检查结果。下面是它做的事，出错时可以手动一步步来。

### 3.1 克隆

```powershell
cd D:\study
git clone https://github.com/astroinec/cv-learning-course.git
cd cv-learning-course
```

参考答案在同一个仓库的 `solutions` 分支，先自己做，做完再看（见根目录 `AGENTS.md` 里的说明）。

### 3.2 虚拟环境

```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
```

PowerShell 提示“禁止运行脚本”时，先运行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，或者改用 cmd 运行 `.venv\Scripts\activate.bat`。

以后每次打开新终端，都要先在仓库根目录运行 `.venv\Scripts\activate`，命令行前面出现 `(.venv)` 才对。

### 3.3 先装带 CUDA 的 PyTorch

**这一步必须在装 `requirements.txt` 之前做**。直接 `pip install torch` 在 Windows 上装到的是只能用 CPU 的版本。

1. 运行 `nvidia-smi`，能看到显卡型号（RTX 4060）和右上角的 “CUDA Version”，说明驱动正常。看不到就先到 NVIDIA 官网或 GeForce Experience 更新驱动。
2. 打开 PyTorch 官网首页的安装选择器（Get Started），依次选 Stable、Windows、Pip、Python、一个 CUDA 版本，复制它生成的命令运行。CUDA 版本选不超过 `nvidia-smi` 右上角数字的那一个。写这份文档时（2026 年 11 月）官网给出的命令形如：

   ```powershell
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
   ```

   `cu126` 的部分以官网当时的选项为准。只想用 CPU 的话把它换成 `cpu`。

3. 确认装对了：

   ```powershell
   python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0) if torch.cuda.is_available() else '')"
   ```

   应该打印版本号（带 `+cu126` 之类的后缀）、`True` 和显卡名。打印 `False` 时，多半是装成了 CPU 版：`pip uninstall torch torchvision` 后重做第 2 步。

### 3.4 装课程的其余依赖

```powershell
pip install -r requirements.txt
python -m ipykernel install --user --name cv-learning --display-name "Python 3 (cv-learning)"
```

`requirements.txt` 里不写 PyTorch 的 CUDA 版本，上一步装好的 PyTorch 不会被替换。课程测过的版本见第 8 节。

## 4. 运行和检查

```powershell
python scripts\check_env.py
```

它逐项检查 Python 版本、各个包、PyTorch 能不能用显卡、matplotlib 有没有中文字体、C++ 编译器、文件读写的编码，并告诉你哪一项不对。

日常使用：

| 想做的事 | 命令（在仓库根目录、已激活 `.venv`） |
|---|---|
| 看课程网页 | 双击 `打开课程网页.bat`，或运行 `python -m http.server 8000` 后浏览器打开 `http://localhost:8000/site/index.html` |
| 打开 Notebook | 双击 `启动课程.bat`，或运行 `python -m jupyter lab .`；内核选 “Python 3 (cv-learning)” |
| 运行某章的验收 | `python "01_像素与色彩\tests\check_progress.py"`（路径里有中文，加引号） |
| 做完一章后对照参考答案 | `git switch solutions` 看 `solutions\` 目录，看完 `git switch main` 回来；或者在网页上看 GitHub 的 `solutions` 分支 |

网页也可以直接在线看：`https://astroinec.github.io/cv-learning-course/`（交互演示和小测都能用，不需要本地环境）。

## 5. 第三部分的可选包

第 25 到 31 章的作业、验收、Notebook 必做部分只用 `requirements.txt` 里的包。每章最后有一节“在自己的机器上用真模型”，需要另装下面的包，并且第一次运行时要联网下载模型权重。**这些包和代码都没有在写课程的机器上运行过**，用到哪章装哪章，装之前先看那一章的说明和各库的官方安装页。

| 章 | 包 | 说明 |
|---|---|---|
| 25 | `timm`（可选） | torchvision 自带的 ViT 已经够用 |
| 26 | `transformers`（二选一） | 另一条路是 `torch.hub` 加载 DINOv2，不用装包，但要联网 |
| 27 | `segment-anything` | 从官方 GitHub 仓库安装，权重从仓库说明里的链接下载 |
| 28 | `open_clip_torch` 或 `transformers` | 开放词汇检测模型也在 `transformers` 里 |
| 29 | `diffusers transformers accelerate` | 模型许可证各不相同，用前看模型卡 |
| 30 | `gsplat`、`nerfstudio`、COLMAP | nerfstudio 和 gsplat 在 Windows 上需要编译 CUDA 扩展，要装 Visual Studio 生成工具和对应版本的 CUDA Toolkit，按它们的官方 Windows 安装说明来；COLMAP 有 Windows 预编译版 |
| 31 | `onnx onnxscript onnxruntime-gpu`、TensorRT | TensorRT 从 NVIDIA 官网下载，版本要和 CUDA 对应；引擎文件和显卡、TensorRT 版本绑定 |

`requirements-optional.txt` 列了其中能直接用 pip 装的那几个，按需取用，不建议一次全装。

8 GB 显存的通用做法：用半精度（`torch.autocast("cuda", dtype=torch.float16)` 或模型自带的 `torch_dtype=torch.float16`）、减小批大小和输入分辨率、推理时包在 `torch.no_grad()` 里、用完的大张量 `del` 掉再 `torch.cuda.empty_cache()`。看显存用 `nvidia-smi` 或 `torch.cuda.max_memory_allocated()`。

## 6. C++ 编译器

只有第 15 章需要。验收脚本 `15_C++视觉工程\tests\check_progress.py` 按环境变量 `CXX`、`g++`、`clang++`、`c++`、`cl` 的顺序找编译器，不需要 CMake 和 OpenCV。三条路选一条：

| 路线 | 适合 | 装好后 |
|---|---|---|
| MSYS2 的 `g++`（推荐） | 想在普通终端里直接用 | 普通 PowerShell 里 `g++ --version` 有输出 |
| Visual Studio 生成工具的 `cl` | 以后要用 Visual Studio 或公司用 MSVC | 只在“x64 Native Tools Command Prompt”窗口里能用 |
| LLVM 的 `clang++` | 想和 macOS、Linux 用同一种编译器 | 还要同时装 Visual Studio 生成工具 |

**MSYS2 的 g++**：

1. 到 MSYS2 官网下载安装包，装在默认位置 `C:\msys64`。
2. 从开始菜单打开 “MSYS2 UCRT64” 终端，运行：

   ```text
   pacman -S mingw-w64-ucrt-x86_64-gcc
   ```

3. 把 `C:\msys64\ucrt64\bin` 加进 Windows 的 `PATH`（设置里搜索“编辑系统环境变量”，在“环境变量”的“Path”里新建一行）。
4. 重新打开 PowerShell，`g++ --version` 能打印版本号就可以。

**Visual Studio 生成工具的 cl**：从 Visual Studio 官网下载 “Build Tools for Visual Studio”，安装时勾选“使用 C++ 的桌面开发”（里面带 CMake）。以后运行第 15 章验收时，从开始菜单打开 “x64 Native Tools Command Prompt for VS”，在这个窗口里 `cd` 到仓库、激活 `.venv`，再运行验收。

**LLVM 的 clang++**：从 GitHub 上 llvm-project 的发布页下载 Windows 安装包，安装时选择把 LLVM 加进 PATH，并按上一条装好生成工具。

第一次运行第 15 章验收时该看到什么、出错先查什么，见第 15 章教程第 7.2 节的“第一次在 Windows 上运行先确认什么”。

想用 CMake 构建（不是必需的）：装了生成工具就带有 CMake；`cmake -S . -B build` 之后用 `cmake --build build --config Release`，Visual Studio 的生成器要在这一步选配置。

## 9. 常见问题

| 现象 | 原因和办法 |
|---|---|
| `pip install` 很慢或超时 | 换国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。PyTorch 的 CUDA 版本只能从第 3.3 节的地址装 |
| `torch.cuda.is_available()` 是 `False` | 装成了 CPU 版，或驱动太旧。先看 `python -c "import torch; print(torch.version.cuda)"`，打印 `None` 就是 CPU 版 |
| 打开文件报 `UnicodeDecodeError: 'gbk' codec` | 课程的代码已经都指定了 UTF-8，这个错多半出在你自己写的代码里：`open(..., encoding="utf-8")` |
| 终端里中文乱码 | 用 Windows Terminal；或者先运行 `chcp 65001` |
| `DataLoader` 卡住或报 `RuntimeError` 提到 `freeze_support` | Windows 上多进程要求代码放在 `if __name__ == "__main__":` 里；课程代码都用 `num_workers=0` |
| 显存不够（`CUDA out of memory`） | 减小批大小或分辨率，见第 5 节末尾 |
| Jupyter 里找不到 “Python 3 (cv-learning)” 内核 | 在激活了 `.venv` 的终端里重新运行第 3.4 节的 `ipykernel install` 那一行 |
| 杀毒软件拦截第 15 章编译出的程序 | 把仓库目录加进白名单，或者换个目录再试 |
