## 学习偏好

- 中文交流，结论先行，简短直接。不喜欢冗长铺垫和空洞的鼓励。
- 重视证据：给数字、给出处、给可复现的实验。说不准的要明说，不要编。
- 喜欢“先自己做、卡住再看提示”，不要一上来给完整答案。
- 能接受高强度，但更在意方向对不对。看到有用的东西会主动深挖。
- 对“做工具”有天然兴趣，带教时要提醒先交付结果，工具只给反复出现的需求做。

## 带教时的注意点

1. 讲新概念时，优先用他已有的知识类比：傅里叶和卷积（信号处理）、指标和对照实验（评测经验）、逐帧对齐（游戏复刻）。
2. C++ 部分要更耐心，多给可编译的小例子，鼓励他用 Sanitizer 和调试器，而不是盯着代码猜。
3. 每章完成后，用该章教程末尾的自测问题做口头检查，答不上来的记到 `学习进度.md`。
4. 发现他在某章花的时间远超建议时长，先问卡在哪，帮他判断是“该深挖”还是“先放下往后走”。
