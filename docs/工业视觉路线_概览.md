# 工业视觉路线：概览版

> 一页看懂。详细的逐日安排见 [工业视觉路线_详细.md](工业视觉路线_详细.md)，可视化版本打开仓库根目录的 `路线图.html`。

## 目标

入职半导体检测设备公司做视觉算法时，第一个月不被工程、术语和基础算法卡住；三个月内能在一个子方向上独立交付。

    A["第一部分 01-14 通用 CV"] --> B["第二部分 15-23 工业视觉专项"]

第一部分已有的 14 章不需要全部重学，按下表挑重点。

## 三种节奏

| 可用时间 | 安排 |
|---|---|
| 2 周（全职投入） | 只做 P0：15 → 16 → 17 → 18 → 23，每章完成作业和自测，实验记录可以简写 |
| 4–6 周（每周 20–25 小时） | P0 加 P1，按详细版的周计划走，最后一周做第 24 章 |
| 8 周以上 | 全部章节，加上 Anomalib 在 MVTec AD 上的实验和 OpenGL 选做 |

## 每章的统一闭环

```text
读教程 → 跑 Notebook 先预测再运行 → 写作业 → 自动验收 → 破坏实验 → 写实验记录 → 回答自测问题
```

自动验收通过只是底线。能回答自测问题、能把失败案例讲清楚，才算学会。

## 入职前的成果清单

- [ ] 第 15 章 C++ 作业全部通过，自己用 CMake 建过一个链接 OpenCV 的工程
- [ ] 第 16、17、18 章作业通过，实验记录里各有一个失败案例分析
- [ ] 第 23 章术语清单整理完，标出待问的问题
- [ ] 第 24 章综合项目验收通过，写完项目报告
- [ ] 能在 5 分钟内讲清一条 die-to-die 检测流水线，以及每一步为什么需要

## 入职后

- 第 1 个月：读懂所在组的代码和配方，跑通一次完整的检测流程，把本仓库学到的东西和实际系统对上号。
- 第 2–3 个月：在一个子方向上独立交付一个改进，用检出率、误报率、耗时说话。
- 持续：把评测习惯带过去，建立缺陷测试集、写清验收口径、做误检和漏检归因。
