## 3. 作业验收加固后仍留的小项

- 第 1 章作业 1-1、1-3 的占位是 `pass` 而不是 `raise NotImplementedError`（这两个作业是“填空”式，骨架里有要保留的代码）。后果：写到“输出全 0”的中值滤波会显示 TODO 而不是 FAIL。要统一需要改骨架，没有动。
