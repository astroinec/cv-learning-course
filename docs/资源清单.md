# 资源清单

> 按主题整理，每条写明“看什么、看多少”。链接核实于 2026 年 11 月，失效时以名称搜索。标了“必看”的是入职前建议完成的。

## 视频课程

| 资源 | 内容 | 建议 |
|---|---|---|
| [First Principles of Computer Vision](https://fpcv.cs.columbia.edu/)（Shree Nayar，哥伦比亚大学） | 成像、传感器、二值图像、滤波、傅里叶、特征、标定、立体、光流、分割 | 必看：Image Formation、Image Sensing、Image Processing II（傅里叶）、Camera Calibration、Depth from Defocus 的 PSF 一节。每节 10–20 分钟，网站按模块列出，视频在 YouTube 频道，也有 Coursera 专项课程 |
| [MIT 6.801 Machine Vision](https://ocw.mit.edu/courses/6-801-machine-vision-fall-2020/)（Berthold Horn） | 成像物理、光度学、运动视觉、工业检测中的模板定位、外方位与光束法平差 | 选看：Lecture 14（工业检测）、Lecture 22（外方位）。偏数学和物理，适合想深入标定和测量的人 |
| 3Blue1Brown：Essence of Linear Algebra | 线性代数的几何直觉 | 第 21 章前看，补矩阵变换直觉 |
| [Hugging Face Diffusion Course](https://huggingface.co/learn/diffusion-course) | 从零实现 DDPM 到 Stable Diffusion | 分到数据生成方向时必看第 1–2 单元 |

## 文字教程

| 资源 | 内容 | 建议 |
|---|---|---|
| [LearnCpp](https://www.learncpp.com/) | 系统的 C++ 教程 | 必看：引用、const、vector、类、智能指针相关章节 |
| [OpenCV 官方教程](https://docs.opencv.org/4.x/d9/df8/tutorial_root.html) | Mat、遍历、滤波、特征、标定 | 必看：Mat 基础、高效遍历图像、相机标定 |
| [CMake 官方教程](https://cmake.org/cmake/help/latest/guide/tutorial/index.html) | 构建系统 | 前 4 步 |
| [LearnOpenGL](https://learnopengl.com/) | OpenGL 管线、着色器、光照 | 渲染方向必看：Getting Started 和 Lighting |
| [tinyrenderer](https://github.com/ssloy/tinyrenderer) | 约 500 行 C++ 从零写软件渲染器 | 第 21 章的 C++ 延伸练习 |
| [Scratchapixel](https://www.scratchapixel.com/) | 光栅化、投影矩阵、光线追踪推导 | 查推导时看 |
| [The Book of Shaders](https://thebookofshaders.com/) | 片元着色器交互式入门 | 选看 |

## 论文

| 论文 | 对应章节 | 读法 |
|---|---|---|
| Zhang, A Flexible New Technique for Camera Calibration（TPAMI 2000） | 17 | 读第 2、3 节和附录 |
| Guizar-Sicairos 等, Efficient subpixel image registration algorithms（Optics Letters 2008） | 16 | 读方法部分，理解上采样 DFT |
| Roth 等, Towards Total Recall in Industrial Anomaly Detection（CVPR 2022，PatchCore） | 19 | 精读方法和消融 |
| Defard 等, PaDiM（ICPR 2021） | 19 | 读方法 |
| Batzner 等, EfficientAD（WACV 2024） | 19 | 了解快速部署方案 |
| Bergmann 等, The MVTec Anomaly Detection Dataset（IJCV 2021） | 19 | 读评测协议和 PRO 指标 |
| Ho 等, Denoising Diffusion Probabilistic Models（2020） | 20 | 读第 2、3 节 |
| Zavrtanik 等, DRAEM（ICCV 2021）；Li 等, CutPaste（CVPR 2021） | 20 | 了解用合成异常训练检测器 |

## 工具和库

| 工具 | 用途 |
|---|---|
| [Anomalib](https://github.com/open-edge-platform/anomalib) | 异常检测算法库，内置 PatchCore、PaDiM、EfficientAD 等，支持 OpenVINO 导出 |
| [Ultralytics YOLO](https://github.com/ultralytics/ultralytics) | 监督检测基线 |
| [Diffusers](https://huggingface.co/docs/diffusers) | 扩散模型，含 inpainting 和 ControlNet |
| scikit-image | `phase_cross_correlation` 等配准函数，可对照第 16 章 |
| OpenCV（Python 和 C++） | 全书的对照基线 |
