# 工业视觉路线：详细版

> 按 6 周、每周约 20–25 小时编排（每个工作日约 3–4 小时，周末各 2–3 小时）。时间更少时，按 [概览版](工业视觉路线_概览.md) 的优先级裁剪。每天的任务以“做完什么”为单位，而不是“学几个小时”。

## 第 0 天：环境准备（2 小时）

1. 克隆仓库，按根目录 README 建虚拟环境并安装依赖，注册 `cv-learning` 内核。
2. 确认 C++ 编译器可用：`c++ --version`。可选安装 `brew install cmake opencv`。
3. 运行一遍所有章节的验收脚本，确认全部显示 TODO 而不是报错：

   ```bash
   for d in */tests/check_progress.py; do python3 "$d" | tail -1; done
   ```

4. 打开 `学习进度.md`，填上开始日期。

## 第 6 周：按分配方向补强，或者复习

入职前如果已经知道分到哪个方向：

- **渲染和仿真方向**：第 21 章全部，加上 LearnOpenGL Getting Started 部分，写出带光照的旋转立方体。
- **数据生成方向**：第 20 章全部，加上 Diffusers 课程第 1–2 单元，跑一次 inpainting。
- **检测算法方向**：回到第 5、6 章（特征点、光流）补完，再看 YOLO 和 U-Net 在小目标缺陷上的做法（第 11、12 章）。
- **标定方向**：第 17 章加非线性优化（自己写一个 LM 或用 scipy），研究远心镜头模型。

还不知道方向：做第 21 章（3D 数学是通用基础），再把前面各章的自测问题全部过一遍。

## 入职后 90 天

| 阶段 | 目标 | 具体动作 |
|---|---|---|
| 第 1–2 周 | 环境和全貌 | 编通组里的代码；跑一次完整检测流程；画出系统数据流图；术语清单逐项问清楚 |
| 第 3–4 周 | 读懂一个模块 | 选一个和自己方向相关的模块，读懂代码、配方参数和历史问题；对照本仓库对应章节 |
| 第 2 个月 | 小改进 | 接一个明确的小任务，比如某类误报的过滤、某个参数的自动标定、某段代码的提速；交付时附上前后对比数据 |
| 第 3 个月 | 独立负责 | 在一个子方向独立负责一块；建立该方向的回归测试集和指标看板 |

持续要做的事：

- 每次改动都留一份前后对比：检出率、误报率、耗时，以及用的是哪批数据。
- 维护自己的“教训清单”，同样的错误出现第二次就写下来并改流程。
- 每月回看一次 `学习进度.md`，把工作中发现的知识缺口补进来。
