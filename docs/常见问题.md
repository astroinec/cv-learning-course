# 常见问题

## 环境

**验收脚本报 `ModuleNotFoundError: No module named 'numpy'`（或 cv2、torch）**
没有激活课程的虚拟环境。按根目录 README 建 `.venv` 并 `source .venv/bin/activate`。第二部分（15–24 章）的作业和验收只依赖 NumPy；第一部分的第 1、5 章需要 OpenCV，第 9–13 章需要 PyTorch，必须在装好 `requirements.txt` 的环境里运行。

**macOS 上运行时打印 `RuntimeWarning: overflow encountered in matmul` 或 `divide by zero encountered in matmul`**
NumPy 2.0 在部分 macOS 版本上调用系统 Accelerate 库做矩阵乘法时，会打印这类误报警告，计算结果是正确的。升级 NumPy 到 2.1 以上通常就没有了。如果结果也异常（出现 NaN），那才是自己代码的问题。

**第 15 章提示找不到编译器**
macOS 运行 `xcode-select --install` 安装命令行工具。Linux 安装 `g++`。

**CMake 找不到 OpenCV**
`brew install opencv` 后，一般 `find_package(OpenCV REQUIRED)` 能自动找到。找不到时加 `-DOpenCV_DIR=$(brew --prefix opencv)/lib/cmake/opencv4`。

**Notebook 里中文显示成方框**
Notebook 开头已经设置了常见中文字体。还不行时，在 `plt.rcParams["font.sans-serif"]` 里加上你系统里有的中文字体名。

## 作业和验收

**验收全是 TODO，是不是坏了？**
不是。作业文件里的函数初始都会抛出 `NotImplementedError`，这是正常的起始状态。

**我的实现在 Notebook 里看起来对，验收却 FAIL**
先看 FAIL 后面的说明，它会指出是哪个不变量没满足。最常见的原因：返回类型不对（要 Python float，返回了 numpy.float64 也可以，但返回 numpy 数组不行）、方向约定写反、边界没处理。

**可以用 OpenCV 或 SciPy 完成作业吗？**
作业要求从零实现核心逻辑（每个作业文件开头写了限制），这样才能真正理解。Notebook 里可以随意用 OpenCV 对照。

**第 24 章我的流水线在调试种子上很好，验收种子上不行**
可能对调试种子过拟合了参数，或者有偶然因素。用 10 个以上种子统计指标再定参数。

**参考答案在哪里？**
在仓库的 `solutions` 分支。建议做完一章、验收通过之后再对照，看看有没有更简洁的写法。不要在卡住的第一时间就看，先读 FAIL 说明、回看教程、问 AI 要提示。

## 学习方法

**某一章花的时间远超建议怎么办？**
先判断卡在哪：概念没懂（回看教程和推荐视频）、实现细节（看 FAIL 说明、加打印）、环境问题（看本文件）。如果是可选的深入内容，先放下往后走，在 `学习进度.md` 里记一笔以后回来。

**第一部分 14 章要全部做完才能进第二部分吗？**
不需要。按 `docs/工业视觉路线_概览.md` 的优先级，P0 里只包括 01–03 章，04、05、07 是 P1，其余按需回看。
