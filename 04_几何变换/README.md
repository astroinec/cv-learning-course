# 第 4 章：几何变换

本章用时建议 **5–7 小时**。目标是理解齐次坐标、映射方向、插值和单应矩阵的平面假设。

## 学习顺序

1. 阅读 `教程_几何变换.md`（原教程保留）。
2. 运行 `实验_几何变换.ipynb`，调节透视强度并观察矫正结果。
3. 独立完成 `4-1_齐次点变换.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 中记录点序错误或退化点集的表现。

## 文件

| 文件 | 用途 |
|---|---|
| `教程_几何变换.md` | 仿射、单应、RANSAC 与拼接教程 |
| `实验_几何变换.ipynb` | 合成网格的透视扭曲与矫正 |
| `4-1_齐次点变换.py` | 从零应用单应矩阵到二维点 |
| `tests/check_progress.py` | 恒等、尺度不变性与无穷远检查 |
| `data/README.md` | 数据说明 |
| `实验记录.md` | 实验记录模板 |

## 启动与验收

从课程根目录运行 `python -m jupyter lab .`，选择 `cv-learning`。本章目录执行：

```bash
python tests/check_progress.py
```

## 通过标准

- 能区分前向映射和反向采样。
- 知道 NumPy shape 与 OpenCV `dsize` 的宽高顺序。
- 能解释单应矩阵整体缩放不改变投影。
- 作业通过检查并记录至少一个几何退化案例。
