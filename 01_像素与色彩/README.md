# 第 1 章：像素与色彩

本章建议用时 **6-9 小时**，分两到三次完成。目标不是记住 OpenCV API，而是建立“图像就是带数据类型和统计分布的张量”这一基本视角。

## 推荐顺序

1. 阅读 `教程_像素与色彩.md`。
2. 打开 `实验_像素与色彩.ipynb`，逐格运行并修改滑块参数。
3. 完成三个 `.py` 作业；不要从 Notebook 复制答案。
4. 运行 `python tests/check_progress.py` 做自动验收。
5. 填写 `实验记录.md`，至少保存一个失败案例。

## 文件说明

| 文件 | 作用 |
|---|---|
| `教程_像素与色彩.md` | 原理、数学直觉、方法限制 |
| `实验_像素与色彩.ipynb` | 互动演示：dtype、色彩空间、直方图、噪声和滤波 |
| `1-1_直方图均衡化.py` | 从零实现 CDF 映射 |
| `1-2_通道分离与伪彩色.py` | 通道操作与 HSV 亮度增强 |
| `1-3_椒盐噪声与中值滤波.py` | 噪声生成和手写中值滤波 |
| `tests/check_progress.py` | 不泄露答案的自动验收脚本 |
| `data/README.md` | 图片来源、许可与可选数据建议 |
| `实验记录.md` | 参数、结果、失败分析模板 |

## 启动 Notebook

从课程根目录运行：

```bash
./启动课程.command
```

或直接运行：

```bash
python -m jupyter lab .
```

## 作业验收

在本章目录运行：

```bash
python tests/check_progress.py
```

作业尚未完成时，检查器会显示 `TODO`；实现错误时显示 `FAIL`；满足基本性质时显示 `PASS`。自动测试只检查底线，不代表算法理解已经合格。

## 本章通过标准

- 能解释 `uint8` 溢出为什么会发生。
- 能说清 OpenCV BGR 与 Matplotlib RGB 的区别。
- 能用 CDF 解释直方图均衡化，而不是只会调用 API。
- 能说明为什么中值滤波适合椒盐噪声。
- 能展示至少一个方法失败的案例，例如过强均衡化放大噪声，或大窗口中值滤波抹掉细线。
- 三个作业通过自动验收，并完成实验记录。
