# 第 11 章：目标检测与 NMS

本章用时：速通 **3 小时**，标准 **10 小时**，深挖 **12 小时**，各档做什么见教程第 0 节。本章用少量合成框观察 IoU、置信度排序和 NMS 阈值，不训练或下载检测模型。

## 学习顺序

1. 阅读 `教程_目标检测.md`。
2. 运行 `实验_IoU与NMS阈值.ipynb`，修改框位置和阈值。
3. 完成 `作业_批量IoU与类别NMS.py`。
4. 运行 `python tests/check_progress.py`。
5. 在 `实验记录.md` 记录密集目标、边界接触和阈值失败案例。

## 文件说明

| 文件 | 作用 |
|---|---|
| `教程_目标检测.md` | 检测流程、IoU、AP、NMS 与 YOLO 训练教程 |
| `figures/` | 教程配图和 `实测数字.json`（教程里所有数字的来源） |
| `../demos/IoU与NMS.html` | 交互演示，浏览器直接打开 |
| `实验_IoU与NMS阈值.ipynb` | 标量 IoU 与贪心抑制的可视化直觉 |
| `作业_批量IoU与类别NMS.py` | 向量化两两 IoU 与类别感知 NMS |
| `tests/check_progress.py` | 检查两两 IoU（空输入、面积为 0 的框、小框）和 NMS（原始下标、链式重叠、阈值边界、跨类别） |
| `data/README.md` | COCO、VOC 等官方来源与许可提示 |

Notebook 只给小规模标量演示；作业要求独立完成批量、空输入和类别隔离逻辑。
