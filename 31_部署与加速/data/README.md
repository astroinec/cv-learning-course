# 第 31 章数据说明

作业、验收、Notebook 的必做部分和教程里的全部数字，都只用代码生成的缺陷小图（32×32 的 8 位灰度图，竖直线条的背景，一半是良品，另一半带一个亮点、暗点、横划痕或竖划痕，缺陷幅度从弱到强随机），不需要下载任何数据，也不需要任何预训练权重。

教程第 8 节和 Notebook 的选做单元会生成几种文件：导出的 ONNX 模型（可能还有一个放权重的数据文件）、TensorRT 的引擎文件、INT8 的校准缓存。它们都是可以重新生成的产物，放在 `data/external/` 或者系统的临时目录里，不要提交到仓库。引擎文件和校准缓存只在生成它的那台机器、那个 TensorRT 版本上有效，换机器要重新构建。

深挖档可以用的数据：

- 自己的图像：验收量化和半精度时，校准集和验证集里都要有缺陷图，而且要包含最强和最弱的缺陷。
- torchvision 的 ResNet-18（ImageNet 权重）：第 14 章已经用过，可以拿来练习导出和构建引擎。本章的教程没有用它，没有参考数字。
- 第 19 章用过的公开数据（[MVTec AD](https://www.mvtec.com/company/research/datasets/mvtec-ad)，许可 CC BY-NC-SA 4.0，仅限非商业用途；[VisA](https://github.com/amazon-science/spot-diff)，许可 CC BY 4.0）：想在真实的缺陷图上按教程第 9 节验收量化后的模型时用。

下载或自备的数据放 `data/external/`，不要提交到仓库。
